Decisions this sets

  • Map is the home screen, with a Map and List switch.
  • The map needs a dark tile style to match. MapTiler and Protomaps both have one.
  • Dark is the default theme. A light theme for use in sunlight is an open question.
  • The app never calculates routes. Directions is a link.
  • Tag colors double as the pin colors, so the legend is the filter chips.
