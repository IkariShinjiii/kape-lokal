Option 3

Matcha Mist

Pale green, big photos, rounded cards, a soft serif for headings. Calm and clean. Photos carry the design, so cafes with good photos look great and cafes without need a placeholder plan.

Type
Instrument Serif + Quicksand
Home view
Photo cards, search on top
Theme
Light, with a deep green dark mode
Risk: matcha is the hero visually, so coffee-only cafes may feel like second-class listings.

Option 5

Riso Zine

Two-ink print look, like a local zine: blue and pink on paper, mono type, dashed rules. The list numbers are real here, because they rank by distance. Distinct, indie, and cheap to build since it needs few images.

Type
Archivo Black + IBM Plex Mono
Home view
Ranked text list, almost no photos
Theme
Paper and ink, with an inverted night mode
Risk: mono text and a bold look are less approachable for casual users. The pink tag needs care for contrast.
My pick for a first build: Option 3 or Option 4. Option 4 matches the map-centered brief best.
